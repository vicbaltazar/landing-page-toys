# 🧸 Landing Page Toys

Uma landing page responsiva com tema de loja de brinquedos, construída com HTML, CSS e JavaScript.  
O projeto foca em um visual colorido e amigável para apresentar produtos de forma simples.

---

## 🌐 Visualize o projeto

- **Versão online:** https://vicbaltazar.github.io/landing-page-toys/

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura e marcação semântica
- **CSS3:** Estilização, layout responsivo e animações suaves
- **JavaScript:** Interações básicas
- **jQuery:** Manipulação do DOM e eventos
- **ScrollReveal:** Animações de scroll
- **Font Awesome:** Ícones
- **Google Fonts (Poppins):** Tipografia

---

## 🚀 Como Começar

1. Clone ou baixe os arquivos do projeto
2. Abra o arquivo `index.html` no seu navegador
3. Não é necessária configuração adicional - todas as dependências são carregadas via CDN
